# CAF-Terminal: Automated Radar & CVE Scoring

Инвестиционный терминал и аналитический радар по методологии **CAF / CVE**.

Система предназначена для:
1. **Emerging / Incubator Radar:** Автоматический еженедельный поиск недооценённых и быстрорастущих проектов вне Top 100/200 по ончейн-сигналам (динамика TVL, комиссии, сборы, эффективность капитала).
2. **CVE 5-Pillars Scoring:** Оценка фундаментального качества активов по 5 ключевым критериям методологии CVE.
3. **Генерация отчетов:** Автоматическое сохранение аналитических срезов в Markdown и CSV.

---

## 🏛️ 5 Столпов методологии CVE

Каждый проект оценивается по композитной шкале (0–100) с распределением весов:

| Столп | Вес | Что оценивает |
|---|---|---|
| **Business Quality (BQ)** | **25%** | Стратегическая значимость сектора (DePIN, RWA, L1/L2, AI compute, DEX infra), технологический ров, полезность продукта |
| **Economic Value Capture (EVC)** | **25%** | Реальный захват ценности токеном (Buyback & Burn, распределение комиссий/revenue протокола, P/S отношение) |
| **Tokenomics (T)** | **20%** | Риск разводнения (FDV / Market Cap), навес разлоков, график эмиссии |
| **Resilience (R)** | **15%** | Рыночный ранг, ликвидность, мультичейн-присутствие, эффект Линди |
| **Anti-Fragility (Safety)** | **15%** | Устойчивость к регуляторным рискам, отсутствие мем-фактора, защита от эксплойтов |

### Градация уровней CVE:
- **Core Candidate (>= 82 баллов, EVC >= 75):** Базовые активы с подтверждённым сетевым эффектом и прямым захватом ценности.
- **High Conviction (70–81 баллов):** Сильные фундаментальные проекты с высоким качеством и потенциалом перехода в Core.
- **Invest (48–69 баллов):** Качественные протоколы, но с ограниченным захватом ценности или высокой конкуренцией.
- **Watch (< 48 баллов или высокая уязвимость):** Спекулятивные токены, мемы, отсутствие экономической модели.

## 🚀 Быстрый запуск

### 1. Активация виртуального окружения
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Запуск Emerging / Incubator радара
Поиск перспективных проектов с TVL > $1M, положительной динамикой за 7/30 дней и генерацией комиссий:
```powershell
python main.py --radar --top 15
```

### 3. Запуск фундаментального CVE-скоринга
Оценка ключевых активов из вашего пула по 5 столпам:
```powershell
python main.py --cve
```

### 4. Полный запуск (Радар + CVE Скоринг) с обновлением данных:
```powershell
python main.py --refresh
```

## ⚙️ Настройка источников данных

- **DefiLlama:** Работает напрямую без API-ключа (публичные эндпоинты protocols и fees).
- **CoinGecko:** По умолчанию использует публичный лимит. При наличии ключа добавьте в `.env`:
  ```ini
  COINGECKO_API_KEY=ваш_демо_или_про_ключ
  ```
- **Кэширование:** Все запросы к API кэшируются локально в `data/cache/` для минимизации нагрузки и обхода rate-limit.
